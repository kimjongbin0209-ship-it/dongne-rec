# 방문 이력 기반 PersonalFreq–SASRec 순위 결합

뉴욕과 도쿄에서 3km E4를 평가했습니다. 각 요청의 반경 안에서 현재 장소를 빼고 PersonalFreq와 SASRec의 순위를 구했습니다. 모델별 동점은 평균 순위로 바꾸고, `1/(60+순위)`를 가중합했습니다.

요청 시점까지 방문한 후보와 미방문 후보에는 서로 다른 PersonalFreq 가중치를 적용했습니다. 각 그룹에서 두 가중치를 0.0~1.0까지 0.1 간격으로 조합했습니다. 시드 0·1·2의 valid NDCG@10 평균이 가장 높은 쌍을 고정한 뒤 test를 평가했습니다.

3단계의 학습 체크포인트를 사용해 MPS로 추론했습니다. 단독 모델의 3단계 E4 대비 쿼리별 지표 최대 절대 차이는 0입니다.

## test E4와 상위 10개 노출

표의 점수는 NDCG@10입니다. ±는 시드별 평균의 표준편차입니다. E4는 반경 밖과 카탈로그 밖 정답을 miss로 계산합니다. 전역 시간 분할의 등록 신규는 학습 카탈로그에 있는 미방문 정답입니다.
